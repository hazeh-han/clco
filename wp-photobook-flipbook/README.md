# WP Photobook Flipbook

유료 플러그인 없이, 사진을 실제 책처럼 페이지를 넘겨서 보여주는 워드프레스 숏코드 플러그인입니다. 외부 JS 라이브러리 의존 없이 순수 CSS 3D transform으로 동작해서 가볍게 운용할 수 있어요.

## 요구 사항

- 워드프레스뿐입니다. **추가 플러그인이 필요 없어요.**
  - (ACF의 "갤러리" 필드 타입은 ACF **PRO**에서만 제공돼서, 무료 ACF로는 쓸 수 없습니다. 그래서 이 플러그인은 기본적으로 워드프레스에 내장된 **갤러리 블록**에서 사진을 읽어옵니다.)

## 사용법

### 1. 사진 올릴 페이지 만들기

**페이지 → 새로 추가**로 페이지를 만듭니다 (예: "할머니 생신 포토북").

### 2. 워드프레스 기본 갤러리 블록에 사진 올리기

1. 본문 편집 영역에서 `+` 버튼 클릭 → **"갤러리"** 블록 검색 → 추가
   (ACF 아님! 워드프레스에 원래 내장되어 있는, 무료인 블록입니다.)
2. **미디어 라이브러리** 선택 → 사진 80장 한 번에 업로드/선택
3. 삽입하면 사진들이 그리드로 보이는데, 드래그해서 원하는 순서로 정렬

### 3. 숏코드 삽입

같은 페이지 본문에, 방금 넣은 갤러리 블록 **바로 아래**에 새 블록을 추가하고 다음을 입력합니다.

```
[wp_photobook]
```

### 4. 발행 후 확인

**발행** → 페이지 열어서 책이 잘 넘어가는지 확인합니다.

이게 끝입니다. 화살표 키, 책 좌우 클릭, 하단 슬라이더로 넘어가는지 확인해보세요.

---

## (선택) ACF PRO를 이미 쓰고 있다면

ACF PRO 라이선스가 있어서 "갤러리" 필드 타입을 쓸 수 있는 경우, 워드프레스 갤러리 블록 대신 ACF 갤러리 필드를 연결할 수도 있습니다.

1. ACF에서 **Gallery** 타입 필드 추가 (필드명 예: `photo_gallery`), 위치 규칙을 해당 페이지로 지정
2. 그 페이지에서 필드에 사진 업로드
3. 숏코드에 `source="acf"`를 추가해 ACF 쪽을 우선 사용하도록 지정:

```
[wp_photobook source="acf" field="photo_gallery"]
```

`source` 속성을 생략하면(`auto`, 기본값) 갤러리 블록을 먼저 찾고, 없을 때만 ACF 필드를 시도합니다.

## 숏코드 옵션

| 속성              | 기본값              | 설명                                                                 |
| ----------------- | -------------------- | ---------------------------------------------------------------------- |
| `source`          | `auto`                | `auto`(갤러리 블록 우선, 없으면 ACF) / `block`(갤러리 블록만) / `acf`(ACF 필드만) |
| `field`           | `photo_gallery`      | `source="acf"`일 때 사용할 ACF 갤러리 필드명                          |
| `post_id`         | 현재 페이지          | 다른 페이지의 사진을 불러오고 싶을 때 사용                             |
| `size`            | `large`              | 사용할 워드프레스 이미지 사이즈 (`medium`, `large`, `full` 등)         |
| `cover`           | `yes`                | 표지/뒤표지를 자동 생성할지 여부 (`no`로 끄면 사진만 바로 시작)        |
| `cover_title`     | 사이트 제목          | (이미지 표지가 없을 때) 표지에 표시할 제목                             |
| `cover_subtitle`  | `{장수} PHOTOGRAPHS` | (이미지 표지가 없을 때) 표지에 표시할 부제                             |
| `cover_image`     | —                     | 직접 만든 이미지를 앞표지로 사용. 미디어 라이브러리 URL 또는 첨부파일 ID |
| `back_cover_image`| —                     | 뒤표지 이미지. `cover_image`와 같은 방식                                |

예시 (글자 표지):

```
[wp_photobook size="large" cover_title="우리 결혼식" cover_subtitle="2026.05.10"]
```

예시 (직접 만든 이미지 표지):

```
[wp_photobook cover_image="https://내사이트.com/wp-content/uploads/2026/09/cover.jpg"]
```

`cover_image`/`back_cover_image`를 지정하면 `cover_title`/`cover_subtitle`은 무시되고 그 이미지가 그대로 표지로 쓰입니다. 세로형(5:7 비율, 예: 1000×1400px)에 가깝게 만들면 잘리는 부분 없이 깔끔하게 들어갑니다.

## 설치

1. `wp-photobook-flipbook` 폴더를 사이트의 `wp-content/plugins/`에 업로드합니다.
2. 워드프레스 관리자 → 플러그인 메뉴에서 **WP Photobook Flipbook**을 활성화합니다.

## 성능 관련 메모

- 처음에는 현재 스프레드에 필요한 이미지 2장만 불러오고, 다음/이전 스프레드 이미지만 미리 한 장씩 더 준비해둡니다(전체 80장을 한 번에 불러오지 않음).
- `size` 속성을 `full`이 아니라 `large`나 `medium_large` 정도로 지정하면 워드프레스가 자동 생성한 리사이즈본을 쓰게 되어 로딩이 훨씬 가벼워집니다.
- 화면이 좁아지면(모바일) 자동으로 한 번에 한 장씩 보는 모드로 전환됩니다.

## 갤러리 원본 그리드 숨기기

갤러리 블록은 사진 데이터를 읽어오는 용도로만 쓰고, 화면에는 책(플립북)만 보이게 하고 싶다면:

1. 편집기에서 갤러리 블록을 클릭해서 선택
2. 오른쪽 사이드바 맨 아래 **"고급(Advanced)"** 섹션을 펼치기
3. **"추가 CSS 클래스(Additional CSS class(es))"** 칸에 `wppb-hide-gallery` 입력
4. 저장/업데이트

이렇게 하면 갤러리 그리드는 화면에서 사라지고, 그 아래 `[wp_photobook]` 숏코드가 만든 책만 보입니다.

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| "사진을 찾을 수 없습니다" 문구 | 숏코드 위에 갤러리 블록이 없거나 비어 있음 → 2단계부터 다시 확인 |
| 사진 순서가 이상함 | 갤러리 블록에서 드래그로 순서를 다시 맞춘 뒤 다시 발행 |
| 로딩이 느림 | `size="medium_large"`처럼 원본보다 작은 사이즈를 지정하세요 |

## 커스터마이징

디자인(색상, 폰트, 여백)은 `wp-photobook-flipbook.php`의 `wp_photobook_styles()` 함수 안 CSS에서 `--wppb-*` 커스텀 프로퍼티를 바꿔서 조정할 수 있습니다. 라이트/다크 모드 색상이 모두 정의되어 있습니다.

사진 페이지는 원본 비율을 유지한 채 여백(매트)을 두고 표시됩니다(실제 앨범처럼). 표지/뒤표지는 매트 없이 페이지를 꽉 채웁니다. 여백 두께는 CSS의 `.wppb-slot img, .wppb-face img { padding: 7%; }`에서 `7%` 숫자를 바꾸면 더 넓거나 좁게 조정할 수 있습니다.
